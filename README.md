# ST-Link V2 Driver Manager ARM64 0.1.0
Experimental Windows 10/11 Rust GUI for USB VID 0483 PID 3748 only. Install Rust MSVC and Visual Studio C++ build tools, run Build.bat, then Run_As_Admin.bat. Native host architecture is used. Windows PowerShell 5.1 is required for SetupAPI interop; the GUI is Rust, driver operations use embedded C# P/Invoke. No custom unsigned driver or security bypass.

Close CubeIDE/OpenOCD before changes. Refresh, record original INF, list candidates, choose exact INF from list, confirm and apply. If winusb.inf is absent, stage a trusted signed compatible INF using the GUI; no automatic driver signing or forced incompatible installation. Restore by selecting original compatible INF. If absent, reinstall the original signed package. Refresh and verify service after changes. For custom GUID, enter the exact GUID required by your application (not supplied here), add it only after WinUSB is active, then restart and verify. Existing GUIDs are retained. Registry permissions may block changes even as administrator; no ACL changes are attempted. No automatic rollback. No hardware or Windows build testing was performed. Candidate selection uses first matching INF; multiple entries sharing the same INF may require future refinement.

Microsoft PnPUtil: https://learn.microsoft.com/en-us/windows-hardware/drivers/devtest/pnputil-command-syntax
